# Energy Demand Forecasting

End-to-end hourly electricity demand forecasting for SPP (Southwest Power Pool) and ERCOT, with weather features.
Built as a learning project for MS-level data analytics, with emphasis on rigorous backtesting and beating seasonal naive baseline.

## Stack
- Python 3.11+
- DuckDB (embedded analytical DB)
- dbt-core + dbt-duckdb (transformations & testing)
- Future: scikit-learn / XGBoost / LightGBM / statsmodels, MLflow, FastAPI, Streamlit
